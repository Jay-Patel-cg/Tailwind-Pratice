# 🎨 Tailwind Practice

A collection of projects and components built while learning and practicing Tailwind CSS. This repository showcases different UI designs, layouts, and responsive components created using a utility-first approach.

---

## 🚀 Features

- 🎯 Practice-based Tailwind CSS projects  
- 📱 Fully responsive designs  
- 🎨 Modern UI components  
- ⚡ Fast styling using utility classes  
- 🧩 Reusable layouts and sections  

---

## 🏗️ Tech Stack

- HTML5  
- Tailwind CSS  
- JavaScript (if used)

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/Jay-Patel-cg/Tailwind-Pratice.git
cd Tailwind-Pratice
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run Tailwind build
```bash
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
```
